# Über diese Website

`ben7sys.github.io` ist eine öffentliche technische Wissensbasis mit Werkzeuglabor.

## Zweck

- belastbares Architektur- und Betriebswissen dokumentieren
- wiederverwendbare Lösungswege nachvollziehbar machen
- kleine Werkzeuge ohne unnötiges Backend bereitstellen
- nachhaltige Systeme, Automatisierung und digitale Souveränität praktisch fördern

## Veröffentlichungsgrundsätze

Veröffentlicht werden nur bereinigte Inhalte ohne Zugangsdaten, interne Systemnamen, Kundendaten oder vertrauliche Infrastrukturdetails. Fakten, Annahmen und bekannte Grenzen werden unterscheidbar dokumentiert.

## Datenschutz

Werkzeuge sollen Eingaben grundsätzlich lokal im Browser verarbeiten. Abweichungen werden direkt am jeweiligen Werkzeug ausgewiesen.

## Quellcode

Der Quellcode dieser Website liegt im öffentlichen Repository [ben7sys/ben7sys.github.io](https://github.com/ben7sys/ben7sys.github.io).
