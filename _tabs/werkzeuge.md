# Werkzeuglabor

Kleine, klar begrenzte Werkzeuge für technische Dokumentation und Systemarbeit.

## Markdown-Frontmatter-Prüfer

Prüft YAML-Frontmatter direkt im Browser auf Struktur, doppelte Schlüssel und leere Werte.

- keine Dateiübertragung
- keine Speicherung
- keine externen APIs
